# Persona

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Personal use by the owner in Brazilian Portuguese, for professional military communication and personal conversations, including former partners.

## Product Purpose

Analyze incoming messages and generate responses that reflect the owner's writing style and selected personality traits.

## Operating Context

Paste a question, statement, or conversation; optionally analyze intention and emotion; generate, adjust, copy, and save a response. Practice conversations and teach the app using real examples.

## Capabilities and Constraints

Existing Next.js app with seven views: Decidir e responder, Pergunta, Afirmação, Conversa, Treino, Meu estilo, Modelos. Preserve provider integration, local profile/history, theme preference, audio, screenshot import, simulation, and export. The decision area adds explicit intent/limits, grounded draft review, user-confirmed pending records scoped by subject, source conflict comparison, and reviewed local alias substitution. Aliases apply only to this area. No authority or military rules are inferred. An optional Span-01 Lite evaluator uses the OpenRouter Decisions API. Installation is available as a PWA; AI requires a network connection.

## Brand Commitments

Keep the name Persona and Brazilian Portuguese. User delegated visual decisions and requested direct implementation without previews.

## Product Principles

Make the received message and response the main workspace. Keep advanced settings available without competing with the main task. Preserve saved data and existing behavior.
