# Persona

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Personal use by the owner in Brazilian Portuguese, for professional military communication and personal conversations, including former partners.

## Product Purpose

Analyze incoming messages, generate responses that reflect the owner's writing style and selected personality traits, and support spoken practice, reflection, and preparation for in-person communication.

## Operating Context

Paste a question, statement, or conversation; optionally analyze intention and emotion; generate, adjust, copy, and save a response. Practice conversations, rehearse a spoken explanation, reflect on real conversations, prepare WhatsApp updates for service-order execution, and teach the app using real examples.

## Capabilities and Constraints

Existing Next.js app with eight views: Decidir e responder, Pergunta, Afirmação, Conversa, Treino, Comunicação na prática, Meu estilo, Modelos. The practical communication view groups oral rehearsal, a manual post-conversation journal and manual service-order status updates with required photo attachment for WhatsApp sharing. No order, regulation, rank, or completion status is inferred; the user supplies and confirms the report. Audio and image data are temporary. Preserve provider integration, local profile/history, theme preference, audio, screenshot import, simulation, and export. The decision area adds explicit intent/limits, grounded draft review, user-confirmed pending records scoped by subject, source conflict comparison, and reviewed local alias substitution. Aliases apply only to this area. An optional Span-01 Lite evaluator uses the OpenRouter Decisions API. Installation is available as a PWA; AI requires a network connection.

## Brand Commitments

Keep the name Persona and Brazilian Portuguese. User delegated visual decisions and requested direct implementation without previews.

## Product Principles

Make the received message and response the main workspace. Keep advanced settings available without competing with the main task. Preserve saved data and existing behavior.
